OPTIMAL DESIGN OF PROPOTIONAL RESONANT CONTROLLER USING 11 LEVEL MULTILEVEL CASCADED H-BRIDGE INVERTER

PRO views   Updated OCTOMBER 2026

This project focuses on designing and optimizing a Proportional-Resonant (PR) controller for an 11-level Cascaded H-Bridge (CHB) multilevel inverter to improve output waveform quality and reduce Total Harmonic Distortion (THD).


The system uses multiple H-bridge power cells connected in series to generate a stepped AC output voltage that closely approximates a sinusoidal waveform. A PR controller is implemented to improve AC tracking performance and minimize steady-state error at the fundamental frequency. An LC filter is used to further suppress switching harmonics and enhance the quality of the output waveform.


The proposed system is modelled and simulated using MATLAB/Simulink to evaluate its performance, waveform characteristics, and harmonic distortion.

Project Overview

Optimal Design of Proportional-Resonant Controller for an 11-Level Cascaded H-Bridge Multilevel Inverter
Project Overview
This project focuses on the design, modelling, and optimization of a Proportional-Resonant (PR) controller for an 11-level Cascaded H-Bridge (CHB) multilevel inverter. The primary objective is to improve AC output waveform quality, minimize harmonic distortion, and achieve accurate tracking of a sinusoidal reference signal.

Multilevel inverters are widely used in modern power conversion applications because they can generate high-quality AC voltage waveforms using multiple lower-voltage DC sources and semiconductor switching devices. Compared with conventional two-level inverters, multilevel topologies offer several advantages, including reduced voltage steps, improved waveform quality, and the potential to reduce output filtering requirements.

In this project, an 11-level Cascaded H-Bridge inverter is modelled in MATLAB/Simulink. A Proportional-Resonant controller is designed to regulate the AC output response, while an LC filter is incorporated to attenuate high-frequency switching harmonics. The system's performance is analysed through simulation, with particular emphasis on waveform quality, harmonic distortion, and reference-tracking behaviour.

1. Cascaded H-Bridge Multilevel Inverter The Cascaded H-Bridge topology consists of multiple single-phase H-bridge power cells connected in series on the AC side. Each cell contributes a controlled voltage level to the overall output, allowing the inverter to generate a stepped waveform that approximates a sinusoidal signal. For an 11-level inverter with equal DC voltage sources, five H-bridge cells are connected in series per phase, producing eleven distinct output voltage levels ranging from \(-5V_{dc}\) to \(+5V_{dc}\), assuming each cell has a DC voltage of \(V_{dc}\). The stepped output waveform offers a closer approximation to a sinusoidal waveform than a conventional two-level inverter. This can help reduce harmonic content and improve power quality, depending on the switching strategy and operating conditions.

2. Proportional-Resonant Controller Design The Proportional-Resonant controller is a control strategy commonly used in AC systems where accurate sinusoidal reference tracking is required. Unlike a conventional Proportional-Integral (PI) controller, which is naturally suited to eliminating steady-state error in DC regulation, a PR controller provides high gain at a selected AC resonant frequency. The proportional component provides a fast response and helps improve system stability and transient behaviour. The resonant component provides high gain around the fundamental frequency, helping the controlled output track the sinusoidal reference with minimal steady-state error. An ideal PR controller can be represented as: \[ G_{PR}(s)=K_p+\frac{K_r s}{s^2+\omega_0^2} \] Where: - \(K_p\) is the proportional gain. - \(K_r\) is the resonant gain. - \(\omega_0\) is the fundamental angular frequency in rad/s. - \(s\) is the Laplace operator. The controller parameters are selected and optimized to achieve the desired control response. In practical implementations, a non-ideal PR controller may be used to provide a finite bandwidth around the resonant frequency.

3. System Modelling and Control Strategy The complete inverter system is developed and simulated in MATLAB/Simulink. The model integrates the multilevel power circuit, control system, switching logic, and output filtering stage. The control process begins with a sinusoidal reference signal representing the desired AC output. The actual output is compared with the reference to generate an error signal. The PR controller processes this error and generates a control signal for the inverter's switching or modulation strategy. The switching logic controls the semiconductor devices in the H-bridge cells to produce the required output voltage levels. The resulting waveform passes through an LC filter, which attenuates unwanted high-frequency components before the output is evaluated. The overall control and simulation process involves: 1. Generating the sinusoidal reference signal. 2. Measuring and comparing the output with the reference. 3. Processing the tracking error through the PR controller. 4. Generating appropriate inverter switching signals. 5. Producing the 11-level AC output waveform. 6. Applying LC filtering to suppress switching harmonics. 7. Evaluating output waveform quality and harmonic distortion.

4. LC Filter and Harmonic Reduction Power electronic inverters generate switching harmonics because semiconductor devices operate through discrete switching states. These harmonics can affect output waveform quality and may cause additional losses or interference in connected equipment. An LC filter, consisting of an inductor and capacitor, is used to attenuate selected high-frequency harmonic components while allowing the desired fundamental-frequency component to pass. The filter design involves selecting appropriate inductance and capacitance values based on the fundamental frequency, switching frequency, load conditions, and desired attenuation. Proper coordination between the filter and controller is important because the filter can influence system dynamics and stability. The effectiveness of harmonic reduction is assessed through output waveform analysis and Total Harmonic Distortion measurements.

5. Simulation and Performance Analysis MATLAB/Simulink is used to model the power circuit and evaluate the behaviour of the controller under the selected simulation conditions. The key performance parameters include: - **Output voltage waveform:** Verification of the expected eleven voltage levels. - **Reference tracking:** Assessment of how accurately the output follows the sinusoidal reference. - **Total Harmonic Distortion (THD):** Measurement of harmonic content in the output voltage or current. - **Transient response:** Evaluation of the system's response to changes in reference or operating conditions, where tested. - **Filter performance:** Analysis of the LC filter's effectiveness in attenuating switching harmonics. - **Controller performance:** Assessment of the selected PR gains and their influence on tracking accuracy and waveform quality. These simulation results provide a basis for evaluating the effectiveness of the proposed controller and identifying suitable parameter settings for the inverter system.

6. Applications The principles explored in this project are relevant to several power conversion applications, including: - Solar photovoltaic power conversion systems. - Renewable energy integration. - Grid-connected inverter systems. - Electric drive and industrial power conversion systems. - High-power AC conversion applications. - Distributed energy resources and modern power systems. The suitability of the proposed configuration for a particular application depends on its electrical ratings, switching strategy, control design, and operating requirements.

7. Engineering Skills and Learning Outcomes This project provides practical exposure to power electronics, AC control systems, multilevel inverter topologies, and simulation-based engineering analysis. Key skills developed include: - Modelling of cascaded H-bridge multilevel inverter circuits. - Understanding and implementation of Proportional-Resonant control. - Analysis of AC reference tracking and harmonic distortion. - Understanding of LC output filter design principles. - MATLAB/Simulink-based system modelling and simulation. - Interpretation of voltage and current waveforms. - Evaluation of power quality and controller performance.

Conclusion The project investigates the use of a Proportional-Resonant controller with an 11-level Cascaded H-Bridge multilevel inverter to improve sinusoidal reference tracking and output power quality. By combining multilevel voltage generation, PR-based control, and LC filtering, the system provides a framework for studying harmonic reduction and controlled AC power conversion. The MATLAB/Simulink model supports the analysis of inverter waveforms, controller behaviour, and harmonic performance. The project demonstrates the application of power electronics and control engineering principles to the development of improved multilevel inverter systems.

import numpy as np


def rms(x):
    """Root-mean-square value."""
    x = np.asarray(x, dtype=float)
    return float(np.sqrt(np.mean(x ** 2)))


def analyse_inverter(
    voltage_reference,
    voltage_measured,
    current_measured,
    sample_rate_hz,
    fundamental_hz=50.0,
    current_reference=None,
    filter_L_h=None,
    filter_C_f=None,
    max_harmonic=40
):
    """
    Analyse synchronized sampled inverter waveforms.

    Voltage/current arrays must use calibrated engineering units:
    volts and amperes.

    Use a steady-state window containing an integer number
    of fundamental cycles for best FFT accuracy.
    """

    vr = np.asarray(voltage_reference, dtype=float)
    v = np.asarray(voltage_measured, dtype=float)
    i = np.asarray(current_measured, dtype=float)

    if not (len(vr) == len(v) == len(i)):
        raise ValueError("Voltage and current arrays must match")

    if len(v) < 16:
        raise ValueError("Insufficient samples")

    if not all(np.all(np.isfinite(x)) for x in (vr, v, i)):
        raise ValueError("Invalid or non-finite samples")

    if sample_rate_hz <= 0 or fundamental_hz <= 0:
        raise ValueError("Invalid sampling/fundamental frequency")

    if fundamental_hz >= sample_rate_hz / 2:
        raise ValueError("Fundamental exceeds Nyquist limit")

    # 1. Voltage difference
    voltage_error = vr - v
    voltage_rms_error = rms(voltage_error)

    voltage_error_mean = float(np.mean(voltage_error))
    voltage_error_peak = float(np.max(np.abs(voltage_error)))

    # 2. Current difference
    current_rms = rms(i)
    current_rms_error = None
    current_error_peak = None

    if current_reference is not None:
        ir = np.asarray(current_reference, dtype=float)

        if len(ir) != len(i) or not np.all(np.isfinite(ir)):
            raise ValueError("Invalid current reference")

        current_error = ir - i
        current_rms_error = rms(current_error)
        current_error_peak = float(
            np.max(np.abs(current_error))
        )

    # 3. Fundamental phase and THD
    # Remove DC offset and apply a Hann window.
    def spectrum(x):
        x = np.asarray(x, dtype=float)
        x = x - np.mean(x)

        window = np.hanning(len(x))
        return np.fft.rfft(x * window)

    V = spectrum(v)
    I = spectrum(i)

    freqs = np.fft.rfftfreq(
        len(v), d=1.0 / sample_rate_hz
    )

    fundamental_bin = int(
        round(fundamental_hz * len(v) / sample_rate_hz)
    )

    if fundamental_bin < 1 or fundamental_bin >= len(freqs):
        raise ValueError("Fundamental bin unavailable")

    def phase_deg(X):
        return float(np.degrees(np.angle(X[fundamental_bin])))

    voltage_phase = phase_deg(V)
    current_phase = phase_deg(I)

    # Positive angle means current leads voltage.
    phase_difference = (
        current_phase - voltage_phase + 180.0
    ) % 360.0 - 180.0

    # THD from harmonic magnitudes relative to fundamental.
    def calculate_thd(X):
        fundamental_mag = abs(X[fundamental_bin])

        if fundamental_mag <= 1e-12:
            return None

        harmonic_power = 0.0

        for h in range(2, max_harmonic + 1):
            idx = int(round(
                h * fundamental_hz * len(v) / sample_rate_hz
            ))

            if idx < len(X) and h * fundamental_hz < sample_rate_hz / 2:
                harmonic_power += abs(X[idx]) ** 2

        return float(
            100.0 * np.sqrt(harmonic_power) / fundamental_mag
        )

    voltage_thd = calculate_thd(V)
    current_thd = calculate_thd(I)

    # 4. LC filter natural/resonant frequency, if L and C are known.
    filter_resonance_hz = None

    if filter_L_h is not None and filter_C_f is not None:
        if filter_L_h <= 0 or filter_C_f <= 0:
            raise ValueError("L and C must be positive")

        filter_resonance_hz = float(
            1.0 / (
                2.0 * np.pi *
                np.sqrt(filter_L_h * filter_C_f)
            )
        )

    return {
        "voltage_rms_error_V": voltage_rms_error,
        "voltage_mean_error_V": voltage_error_mean,
        "voltage_peak_error_V": voltage_error_peak,
        "current_rms_A": current_rms,
        "current_rms_error_A": current_rms_error,
        "current_peak_error_A": current_error_peak,
        "phase_difference_deg": phase_difference,
        "voltage_thd_percent": voltage_thd,
        "current_thd_percent": current_thd,
        "filter_resonance_hz": filter_resonance_hz
    }


if __name__ == "__main__":
    # Demonstration only: synthetic signals, NOT hardware data.
    fs = 10000.0
    f0 = 50.0
    t = np.arange(0, 0.2, 1.0 / fs)

    v_ref = 100.0 * np.sin(2 * np.pi * f0 * t)
    v_meas = (
        98.0 * np.sin(2 * np.pi * f0 * t)
        + 3.0 * np.sin(2 * np.pi * 5 * f0 * t)
    )

    i_ref = 2.0 * np.sin(2 * np.pi * f0 * t)
    i_meas = 1.8 * np.sin(
        2 * np.pi * f0 * t - np.radians(20)
    )

    result = analyse_inverter(
        voltage_reference=v_ref,
        voltage_measured=v_meas,
        current_measured=i_meas,
        current_reference=i_ref,
        sample_rate_hz=fs,
        fundamental_hz=f0,
        filter_L_h=0.01,
        filter_C_f=100e-6
    )

    for name, value in result.items():
        print(f"{name}: {value}")
